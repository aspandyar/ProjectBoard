# Assignment 6 — SPA (Same content as SSR app)

React SPA built with Vite. Same content and structure as **assignment6-ssr** (Next.js SSR/SSG).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Structure

- **Home** — hero + featured articles
- **Articles** — list (from shared data)
- **Article** — detail by slug
- **About** — static page

Content is in `src/data/articles.js` (mirrors SSR app).
